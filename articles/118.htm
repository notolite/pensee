A memorandum for scrcpy over Tailscale

Une note sur l'utilisation de scrcpy via Tailscale

memorandum for myself

Procedure

  1. Enable Tailscale networking on Android
  2. Enable wireless debugging
  3. Check port numbr for wireless debugging
  4. Execute below:
    adb connect (device name):(port number)
# Tailscale DNS available for the device naming
scrcpy

Presuppositions

Linux

  • scrcpy
  • android-tools
  • Tailscale

Android

  • Tailscale
  • Developer's option - enabled
  • Devices on wireless debugging paired

Yes/No that I'm often unsure of

  • USB debugging can be remained off
  • Device pairing persists over toggling wireless debugging
