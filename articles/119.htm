Memorandum: Use of LineApp on Proton-GE

Une note sur l'utilisation du LineApp sur le Proton-GE
07 novembre 2026

This is a memorandum for myself about the way of introducing LINE on Proton-GE with umu-launcher, solving windows dll signature problem.

Reference

  • Linux上的wine一鍵化Line簽署協助安裝工具 - 手把手教學 | 181 Bits
  • HyprlandにLINEをインストールする | snacy on Zenn

Procedures

  1. Download LineInst.exe
    curl -fO https://desktop.line-scdn.net/win/bin/real/installer/LineInst.exe
  2. Download shell script from https://181bit.blogspot.com/2026/08/linux-wine-line.html
    curl -f https://raw.githubusercontent.com/maker181/LineMessenger_Wine/refs/heads/main/fix_line_wine.sh
chmod +x /tmp/fix_line_wine.sh
/tmp/fix_line_wine.sh
    When fix_line_wine.sh prompts to select Bottles windir, indeed the script still works if you select ~/Game/umu/umu-launcher/drive_c/windows/ or wherever.
  3. Prepare two registry files to be used later.

    graphics.reg

    Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Wine\Drivers]
"Graphics"="x11"

[HKEY_CURRENT_USER\Software\Wine\X11 Driver]
"UseEGL"="N

    font.reg

    Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Wine\Fonts\Replacements]
"Arial"="Liberation Sans"
"Arial Unicode MS"="Noto Sans CJK JP"
"MS Shell Dlg"="Liberation Sans"
"MS Shell Dlg 2"="Liberation Sans"
"Segoe UI"="Liberation Sans"
"Segoe UI Semibold"="Liberation Sans"
"Tahoma"="Liberation Sans"
"Verdana"="Liberation Sans"
"Meiryo"="Noto Sans CJK JP"
"Meiryo UI"="Noto Sans CJK JP"
"MS Gothic"="Noto Sans CJK JP"
"MS PGothic"="Noto Sans CJK JP"
"MS UI Gothic"="Noto Sans CJK JP"
"Yu Gothic"="Noto Sans CJK JP"
"Yu Gothic UI"="Noto Sans CJK JP"

[HKEY_CURRENT_USER\Control Panel\Desktop]
"FontSmoothing"="2"
"FontSmoothingGamma"=dword:00000578
"FontSmoothingOrientation"=dword:00000001
"FontSmoothingType"=dword:00000002
  4. Install LINE as normal.
  5. Edit registry. An easier way is to launch Regedit.exe GUI and import two files prepared above.
    umu-launcher regedit.exe
  6. Afrer successfully installed, LINE can be launched with umu-run. It would be convenient to create a script for this.
    #!/bin/bash
umu-run $HOME/Games/umu/umu-default/drive_c/users/steamuser/AppData/Local/LINE/bin/LineLauncher.exe
# above path is for example
    The warning message for signature still appears, but it can be ignored.
